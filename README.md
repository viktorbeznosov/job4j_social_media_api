## Описание

RESTful API для социальной медиа платформы, разработанный на Java с использованием Spring Boot. Платформа позволяет пользователям регистрироваться, создавать посты, взаимодействовать друг с другом, подписываться и получать ленту активности.

## 🚀 Возможности

- **Аутентификация и авторизация** — регистрация, вход, JWT токены, хэширование паролей
- **Управление постами** — создание, чтение, обновление, удаление постов с изображениями
- **Взаимодействие пользователей** — отправка заявок в друзья, управление подписками
- **Сообщения** — обмен сообщениями между друзьями
- **Лента активности** — пагинированная лента постов от подписок
- **Документация API** — Swagger/OpenAPI с полным описанием эндпоинтов

## 🛠 Технологии

- **Java 17**
- **Spring Boot 4.0.4**
- **Spring Security** + **JWT**
- **Spring Data JPA**
- **PostgreSQL / MySQL**
- **Liquibase / Flyway** (миграции базы данных)
- **Maven** (сборка проекта)
- **Swagger/OpenAPI** (документация)
- **JUnit 5, Mockito** (тестирование)
- **GitHub Actions** (CI/CD)
- **Checkstyle** (код-стайл)

## 📋 Требования

- Java 17 или выше
- Maven 40+
- PostgreSQL 18+
